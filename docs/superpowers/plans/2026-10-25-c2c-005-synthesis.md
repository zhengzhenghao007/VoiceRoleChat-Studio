# C2C-005 Synthesis Implementation Plan

> Execute inline using superpowers:executing-plans; ChatGPT independently reviews.

**Goal:** Generate and retrieve a WAV from an existing registered voice model.
**Architecture:** Isolated HTTP synthesis adapter shares the lifecycle lock;
typed API resolves registry data and safe reference inputs, atomic output store.
**Tech Stack:** Existing FastAPI/Pydantic, Python stdlib HTTP/wave/threading.
**Spec:** docs/superpowers/specs/2026-10-25-c2c-005-synthesis.md.

## Constraints and review focus

No external-service mutation, training, installs/downloads, broad frontend work,
or edits to original model/data. Protect against path escape, mixed model pairs,
late upstream requests after a client timeout, invalid/truncated audio, and
concurrent service stop. Existing API stays compatible; single backend process.
