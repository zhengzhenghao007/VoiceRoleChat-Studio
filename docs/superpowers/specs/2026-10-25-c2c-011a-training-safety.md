# C2C-011A Training preparation safety

User continuous-development authorization covers routine design decisions; independent review before publication. Baseline d21b84b. Current training_worker deletes datasets/<experiment> and upstream logs/<experiment>, reuses export/work directories and accepts weak input path names. Do not execute real training.

Choose fail-closed exclusive ownership over backup/overwrite or in-place migration: any existing output is preserved and rejected. Add optional prepared dataset_name while retaining legacy audio/transcript requests. Prepared mode validates Schema2 manifest, character identity, fixed clip paths, per-clip bytes/PCM format/hash and exact safe annotation lines, review snapshot hash. Consume verified immutable dataset files read-only; no rebuild/delete. This is local integrity checking, not OS-enforced immutability; concurrent external edits after validation remain a limitation pending per-job snapshots in011B. Legacy preparation uses existing bounded path/annotation safeguards and exclusive new directory.

Requests accept either dataset_name or both legacy filenames, never mixed. Store dataset_name in job response; old records retain defaults. Validate before background submission and again in worker; unsupported engines rejected before queueing. Name/root canonical boundaries for job/character/dataset paths. Output directories for experiment/work/export created exclusively, never rmtree existing outputs. Known incomplete newly created outputs remain for diagnostics; no rollback deletion of user data. No cancellation/queue claims this part; current daemon thread and subprocess wait remain until011B.

Test only temporary roots and stubs: old dataset collision preserves marker; experiment log collision prevents subprocess; existing model export preserves marker; prepared two clips passed to preprocessing unchanged; tampered/missing/escaping clips and annotation mismatch rejected; API grammar/legacy compatibility/path traversal. Dual Python full regression, no GPU/Whisper/download/install. Independent C2C review required.
