# C2C-005 minimal text synthesis

The user requested continuous autonomous progress through the existing roadmap.
Implementation choices below are Codex's decisions, not separately selected by
the user. Existing FastAPI, registry and managed CPU service remain in place.

## Approach

Use the local HTTP API and serialize weight selection plus synthesis with the
same operation lock as start/stop. Importing upstream ML into FastAPI would
couple incompatible environments; a job queue/streaming layer is premature.
Only the owned ready service may be mutated; external services stay read-only.
Explicit service start remains required. No automatic download or training.

POST /api/tts/synthesize accepts model_id, text (1..1000), text_lang and
prompt_lang (zh/ja/en/ko/yue/all_zh/all_ja/all_ko/all_yue/auto/auto_yue),
reference_audio (project-relative WAV in uploads or datasets), prompt_text
(1..1000). Reference must be readable PCM WAV, 3..10 seconds, at most 10 MiB.
Resolve symlinks and reject traversal/absolute paths and escaped roots.
Get model paths only from the registry; incomplete=409, ambiguous=409,
missing=404. Revalidate weight files within configured training/export roots.

Every request switches GPT and SoVITS in order, then POSTs nonstreaming WAV
inference. Do not cache current model: partial failure must force a fresh pair
on retry. All three HTTP requests share one finite configurable deadline
GPT_SOVITS_SYNTHESIS_TIMEOUT (default 180, maximum 600 seconds), no proxy or
redirect. Weight acknowledgements must be success JSON; audio is bounded at
32 MiB, decoded as nonempty PCM WAV with complete frames. Unknown upstream
responses produce 502; unavailable=503, concurrent operation=409, timeout=504.
On uncertain transport failure/timeout, stop only the owned child before
releasing the lock, preventing late work from contaminating later requests.

Save validated WAV atomically as outputs/tts/<uuid>.wav. Return id, model_id,
audio_url, sample_rate, duration_seconds. GET /api/tts/audio/<uuid> retrieves only
these generated WAVs; never expose arbitrary files. Runtime WAVs are ignored.

## Acceptance

TDD covers validation, registry errors, ordered pair selection, concurrency with
stop/start, bounded slow/large/invalid responses, partial failures, atomic outputs,
safe retrieval, and dependency isolation. Full suites run in Python 3.12/3.10.
Attempt one short CPU synthesis using existing Japanese model/reference and
local dependencies, offline, with explicit owned service cleanup. No installs,
downloads, training or modifications to original resources. If actual inference
is blocked, report the exact error and retain task status PARTIAL; do not count
a fake WAV as real inference acceptance. ChatGPT reviews evidence before push.
